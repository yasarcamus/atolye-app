# Distil - Parfüm Atölyem

Modern, kapsamlı ve profesyonel parfüm üretim takip uygulaması.

## 🎯 Özellikler

### ✅ Tamamlanan Özellikler

#### 🏠 Karşılama & Onboarding
- Profesyonel karşılama ekranı
- Kullanıcı isim girişi
- Özellik tanıtımı

#### 🧪 Üretim Yönetimi
- Yeni üretim başlatma ve takip
- Günlük bildirimler ve geri sayım
- Test girişi ve değerlendirme (kalıcılık, silaj, beğeni)
- Üretim arşivi ve filtreleme
- Detaylı üretim görünümü
- Günlük notlar ekleme
- Favori sistemi

#### 💰 Maliyet Yönetimi
- Hammadde kütüphanesi
- Alkol, su, esans fiyat takibi
- Stok yönetimi
- Otomatik maliyet hesaplama
- Üretim başına maliyet analizi

#### 📚 Reçete Bankası
- Test edilmiş tarifleri görüntüleme
- Favori reçeteler
- Reçete kopyalama
- Başarılı tarifleri tekrar kullanma

#### 📊 Raporlar & Analytics
- Toplam üretim istatistikleri
- Performans ortalamaları (kalıcılık, silaj, beğeni)
- Maliyet analizi
- En çok kullanılan esanslar
- En başarılı üretimler
- En pahalı üretimler

#### ⚙️ Ayarlar & Kişiselleştirme
- Profil yönetimi
- Bildirim ayarları (açma/kapama, saat seçimi)
- **Dark mode** 🌙
- Veri yönetimi
- Premium durum kontrolü

#### 💎 Premium Sistem
- Ücretsiz vs Premium karşılaştırması
- Sınırsız üretim (Premium)
- Sınırsız maliyet hesaplama (Premium)
- Demo aktivasyon

#### 🎨 UI/UX
- Modern ve minimal tasarım
- Gradient arka planlar
- Animasyonlar ve geçişler
- Responsive tasarım
- PWA desteği (telefona kurulabilir)

### 🚀 Gelecek Özellikler
- 📸 Fotoğraf yükleme
- 📄 PDF/Excel export
- 🏷️ QR kod etiket oluşturma
- 👥 Topluluk ve tarif paylaşımı
- 🏢 "Markam" modülü
- 💳 Ödeme entegrasyonu

## Teknoloji Stack

- **Frontend**: React 18 + TypeScript
- **Build**: Vite
- **Styling**: TailwindCSS + shadcn/ui
- **State**: Zustand
- **Database**: IndexedDB (Dexie.js)
- **Icons**: Lucide React
- **PWA**: Vite PWA Plugin

## Kurulum

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Production build
npm run build

# Build'i önizle
npm run preview
```

## Kullanım

1. Uygulamayı açın
2. "Yeni Üretim" butonuna tıklayın
3. Parfüm bilgilerini girin
4. Günlük bildirimleri takip edin
5. Süre dolunca test sonuçlarını girin
